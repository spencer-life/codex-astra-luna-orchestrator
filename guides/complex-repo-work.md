# Complex repository work

The maintained default **GPT-6 Sol High** root is the starting point for difficult
debugging and cross-component work. Keep architecture and ambiguous solution selection
with the root, then delegate bounded implementation to the Luna High worker.

If a particular session genuinely needs more root reasoning, raise the active Sol
effort in the Codex picker/CLI for that session rather than editing the shared
orchestrator config. Measure whether the extra latency improves accepted outcomes
before making a new default.

The independent reviewer is pinned to GPT-6 Sol Max. Substantive repository discovery,
component tracing, and other bounded evidence gathering hit the hard delegation gate
before the root proceeds with architecture or integration.
