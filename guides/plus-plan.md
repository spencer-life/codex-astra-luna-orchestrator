# Luna-root sessions

This file remains for compatibility with older links; the personal v3 setup no longer
maintains separate Plus/Pro orchestration profiles.

To run the whole primary thread on Luna, choose **GPT-6 Luna** in the Codex picker or
start the CLI with the Luna model. The active primary model is treated as the root and
is not overridden by the routing skill.

Named roles remain pinned independently:

- explorer/researcher: GPT-6 Luna Medium
- worker/tester: GPT-6 Luna High
- reviewer: GPT-6 Sol Medium

If you truly want an all-Luna topology including review, that is a separate maintained
policy change rather than a session picker override.
